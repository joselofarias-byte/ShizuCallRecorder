# ShizuCallRecorder — JoseloFarias fork

Fork Android mantenido por **JoseloFarias** para grabación de llamadas mediante Shizuku, con foco en privacidad, estabilidad y uso sin root cuando la plataforma lo permite.

## Objetivos del fork

- Mantener grabación funcional de ambos lados de la llamada en dispositivos compatibles.
- Reducir telemetría, dependencias y componentes no necesarios.
- Mejorar robustez, compatibilidad y experiencia de uso sin degradar funciones útiles.
- Conservar atribución, licencia y referencias al proyecto original.

## Estado

Mantenimiento activo. Las mejoras se validan con la infraestructura real del proyecto y pruebas en dispositivo cuando corresponde.

## Desarrollo

```bash
git clone https://github.com/joselofarias-byte/ShizuCallRecorder.git
cd ShizuCallRecorder
./gradlew assembleDebug
```

## Uso responsable

Verifique la legislación aplicable a grabación de llamadas y consentimiento en su jurisdicción.
